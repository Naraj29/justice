## 🚀 Features

| Feature | Description |
|---|---|
| 🗺️ **Interactive Leaflet Map** | Pan/zoom India, custom SVG markers per category, dark tile theme |
| 📌 **Incident Pinning** | Click the map to pin any location in a multi-step form |
| 📰 **Public Feed** | News-style report cards with search, category & state filters |
| 🔍 **Real-time Search** | Fuzzy search across titles, descriptions, tags & locations |
| 📊 **Stats Dashboard** | Live counters for reports, states covered, and shares |
| 📱 **Share Anywhere** | One-click share to Twitter, WhatsApp, or clipboard |
| ✅ **Verification Badges** | Community-verified reports marked with shield icons |
| 🌙 **Dark Glassmorphism UI** | Premium dark theme with glass cards and micro-animations |

---

## 🗂 Categories

- 🚔 **Police Brutality** — custodial torture, lathi charges, extrajudicial action
- 💰 **Corruption** — bribery, contractor fraud, RTI retaliation
- 🌿 **Environmental Crime** — illegal mining, industrial pollution, NGT violations
- ✊ **Rights Violation** — Dalit rights, housing, healthcare denial, UAPA abuse
- 📰 **Media Suppression** — journalist arrests, sedition cases
- ⚖️ **Judicial Delay** — bail denial, undertrials, UAPA detention

## 🛠 Tech Stack

```
React 19 + Vite 8      → Framework & build
Tailwind CSS v4        → Styling (CSS-first config)
Leaflet + react-leaflet → Interactive maps
Framer Motion          → Animations
React Router v7        → Navigation
date-fns               → Date formatting
uuid                   → Report ID generation
gh-pages               → GitHub Pages deployment
```

## 🏃 Run Locally

```bash
git clone https://github.com/Naraj29/justice.git
cd justice
npm install
npm run dev
```

Open http://localhost:5173/justice

## 🚀 Deploy to GitHub Pages

```bash
npm run deploy
```
